# Área de nomenclatura legada

Esta pasta existe por compatibilidade com documentação criada anteriormente.

- A pasta canônica para PRDs oficiais é `../PRD/`.
- O conteúdo aqui pode ser útil como estudo ou histórico.
- Nenhum arquivo desta pasta deve sobrescrever uma regra normativa de `../PRD/` sem revisão explícita.
- Novos PRDs não devem ser criados aqui.

A migração física do conteúdo remanescente deve ser feita separadamente quando não houver risco de quebrar referências existentes.

## Mercado Pago — exceção documental em transição

Os 17 documentos históricos em `MercadoPago/` **não foram movidos nem duplicados** nesta etapa para evitar quebra de referências. O índice de entrada e o controle de execução estão em [`docs/PRD/MercadoPago/README.md`](../PRD/MercadoPago/README.md). Os registros novos de checkpoint e evidências ficam exclusivamente na pasta canônica; os PRDs históricos permanecem acessíveis até uma migração controlada.
